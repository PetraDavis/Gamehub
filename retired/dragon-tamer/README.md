# Dragon Tamer (retired)

Dragon Tamer was taken out of GAMEHUB on 2026-11-09 because it kept running out of memory on the real TI-84 Evo when started from the GAMEHUB menu.

The code is kept here as a reference (for Wyrmwild, the computer version). It is not built, not in the menu and not on the download page.

- `GHDRAGON.py`: the whole game, as it was. `tools/bundle.py` used to split it into 14 calculator files.
- `dragdata.py`: makes the packed dragon pictures inside `GHDRAGON.py`.
